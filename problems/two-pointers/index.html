Индексы и два указателя

Задачи на работу с индексами: соседние элементы, элементы через один и два указателя с разных концов. Это разминка перед техникой двух указателей.

Задачи

  1. 1. Следующий элемент
  2. 2. Предыдущий элемент
  3. 3. Через один
  4. 4. Соседние равные
  5. 5. Есть ли возрастание
  6. 6. Разница соседей
  7. 7. Строго возрастает?
  8. 8. С двух концов
  9. 9. Палиндромы
  10. 10. Сумма двух чисел

Решай циклом по индексам. Можно использовать len(), range() и append() у списков. Нельзя использовать срезы, zip(), enumerate(), sorted(), reversed(), sum(), min(), max() и методы строк: всё делай через обращение к элементам по индексу.

Как решать

Код запускается прямо в браузере, вывод сразу сравнивается с ожидаемым, а решения сохраняются в этом браузере. При первом запуске загрузится Python — около 13 МБ.

1. Следующий элемент

Дан список:

nums = [10, 20, 30, 40]

Для каждого элемента, у которого есть следующий, выведи пару: сам элемент и следующий за ним. Каждую пару выведи на отдельной строке через пробел.

Подсказка

Пригодится: range(len(nums) - 1), print(a, b)

Ожидаемый вывод

10 20
20 30
30 40

Ctrl+Enter

2. Предыдущий элемент

Дан список:

nums = [10, 20, 30, 40]

Для каждого элемента, у которого есть предыдущий, выведи пару: сам элемент и стоящий перед ним. Каждую пару выведи на отдельной строке через пробел.

Подсказка

Пригодится: range(1, len(nums))

Ожидаемый вывод

20 10
30 20
40 30

Ctrl+Enter

3. Через один

Дан список:

nums = [1, 2, 3, 4, 5]

Для каждого элемента выведи пару: сам элемент и элемент через один после него (индексы i и i + 2). Каждую пару выведи на отдельной строке через пробел.

Ожидаемый вывод

1 3
2 4
3 5

Ctrl+Enter

4. Соседние равные

Дан список:

nums = [1, 2, 2, 3, 4, 4, 5]

Собери в новый список все элементы, которые равны следующему за ними, и выведи этот список.

Ожидаемый вывод

[2, 4]

Ctrl+Enter

5. Есть ли возрастание

Даны два списка:

a = [9, 7, 7, 4, 1]
b = [5, 3, 4, 2, 1]

Для каждого списка проверь, есть ли в нём хотя бы одна пара соседних элементов, где левый меньше правого. Выведи True или False: сначала для a, потом для b.

Подсказка

Пригодится: переменная-флаг found = False, break

Ожидаемый вывод

False
True

Ctrl+Enter

6. Разница соседей

Дан список:

nums = [10, 15, 18, 30]

Составь список разниц между каждым элементом и предыдущим (nums[i + 1] - nums[i]) и выведи его.

Ожидаемый вывод

[5, 3, 12]

Ctrl+Enter

7. Строго возрастает?

Даны два списка:

a = [1, 2, 3, 4, 5]
b = [1, 2, 2, 3, 4]

Для каждого списка проверь, что его элементы строго возрастают: каждый следующий больше предыдущего. Сортировку не используй. Выведи True или False: сначала для a, потом для b.

Вопрос на подумать

Почему список b не строго возрастающий, хотя ни один его элемент не меньше предыдущего?

Ожидаемый вывод

True
False

Ctrl+Enter

8. С двух концов

Дан список:

nums = [1, 2, 3, 4, 5]

Поставь левый указатель на первый элемент, а правый на последний. Пока левый указатель левее правого, выводи пару элементов через пробел, а потом сдвигай левый указатель вправо, а правый влево. Средний элемент, которому не хватило пары, не выводи.

Подсказка

Пригодится: left = 0, right = len(nums) - 1, while left < right

Ожидаемый вывод

1 5
2 4

Ctrl+Enter

9. Палиндромы

Дан список слов:

words = ["level", "python", "abba"]

Для каждого слова проверь двумя указателями, палиндром ли оно: одинаково ли читается слева направо и справа налево. Выведи слово и True или False через пробел, каждое слово на отдельной строке.

Подсказка

Пригодится: сравнивай word[left] и word[right], сдвигая указатели навстречу друг другу

Ожидаемый вывод

level True
python False
abba True

Ctrl+Enter

10. Сумма двух чисел

Дан отсортированный по возрастанию список и число:

nums = [1, 2, 3, 4, 6, 8]
target = 10

Найди пару чисел с суммой target двумя указателями. Левый указатель стоит на первом элементе, правый на последнем. Если сумма меньше target, сдвигай левый указатель вправо, если больше — правый влево. Выведи через пробел первую пару, которую так найдёшь. Если пары нет, выведи None.

Подсказка

Пригодится: while left < right

Дополнительно

В списке есть ещё одна пара с суммой 10. Измени решение, чтобы оно выводило все такие пары.

Ожидаемый вывод

2 8

Ctrl+Enter

10 из 10
