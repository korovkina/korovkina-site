Как решать

Код запускается прямо в браузере, вывод сразу сравнивается с ожидаемым, а решения сохраняются в этом браузере. При первом запуске загрузится Python — около 13 МБ.

1. Доступ по ключу

Дан словарь:

person = {"name": "Alice", "age": 25, "city": "Paris"}

Выведи имя и город, обращаясь к значениям по ключам. Каждое значение — с новой строки.

Ожидаемый вывод

Alice
Paris

Ctrl+Enter

2. Изменение значения

Дан словарь:

person = {"name": "Bob", "age": 30}

Измени возраст на 31 и добавь новый ключ "city" со значением "London". Выведи обновлённый словарь.

Ожидаемый вывод

{'name': 'Bob', 'age': 31, 'city': 'London'}

Ctrl+Enter

3. Добавление и удаление элементов

Дан словарь:

student = {"name": "Kate", "grade": "A"}

Добавь ключ "age" со значением 18 и удали ключ "grade". Выведи получившийся словарь.

Подсказка

Пригодится: del или dict.pop()

Ожидаемый вывод

{'name': 'Kate', 'age': 18}

Ctrl+Enter

4. Проверка наличия ключа

Дан словарь и список ключей, которые нужно проверить:

info = {"login": "user123", "password": "qwerty"}
keys = ["login", "email"]

Для каждого ключа из списка keys по очереди: если ключ есть в словаре, выведи его значение, иначе выведи "Нет такого ключа."

Подсказка

Пригодится: оператор in

Ожидаемый вывод

user123
Нет такого ключа.

Ctrl+Enter

5. Перебор словаря

Дан словарь с оценками учеников:

scores = {"Alice": 90, "Bob": 75, "Charlie": 82}

Выведи всех учеников и их оценки, каждого с новой строки, в формате «имя → оценка».

Подсказка

Пригодится: dict.items()

Ожидаемый вывод

Alice → 90
Bob → 75
Charlie → 82

Ctrl+Enter

6. Сумма значений

Дан словарь:

nums = {"a": 3, "b": 7, "c": 2}

Найди и выведи сумму всех значений.

Подсказка

Пригодится: dict.values(), sum()

Ожидаемый вывод

12

Ctrl+Enter

7. Обратный словарь

Дан словарь цветов:

colors = {"red": "#FF0000", "green": "#00FF00", "blue": "#0000FF"}

Создай новый словарь, где ключи и значения поменялись местами, и выведи его.

Подсказка

Пригодится: dict.items()

Ожидаемый вывод

{'#FF0000': 'red', '#00FF00': 'green', '#0000FF': 'blue'}

Ctrl+Enter

8. Частота букв

Дано слово:

word = "banana"

Создай словарь, где ключ — буква, а значение — сколько раз она встречается в слове. Буквы в словаре должны идти в порядке первого появления в слове. Выведи словарь.

Подсказка

Пригодится: dict.get(ключ, 0)

Ожидаемый вывод

{'b': 1, 'a': 3, 'n': 2}

Ctrl+Enter

9. Вложенные словари

Дан словарь students: ключ — имя ученика, значение — словарь с его данными.

students = {
    "Alice": {"age": 20, "grade": "A"},
    "Bob": {"age": 22, "grade": "B"}
}

Выведи возраст и оценку Боба (ключ "Bob") через пробел.

Ожидаемый вывод

22 B

Ctrl+Enter

10. Форматированный вывод

Дан словарь с данными о товаре:

product = {"name": "Laptop", "price": 1200, "brand": "Dell"}

С помощью f-строк выведи название, бренд и цену в две строки, как в ожидаемом выводе.

Ожидаемый вывод

Товар: Laptop (Dell)
Цена: 1200$

Ctrl+Enter
