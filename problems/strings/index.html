Как решать

Код запускается прямо в браузере, вывод сразу сравнивается с ожидаемым, а решения сохраняются в этом браузере. При первом запуске загрузится Python — около 13 МБ.

1. Первый и последний символ и длина

Дана строка:

title = "Programming"

Выведи каждое с новой строки: первый символ строки, последний символ и фразу «В строке N символов», где N — длина строки.

Подсказка

Пригодится: индексы [0] и [-1], len(), f-строка

Ожидаемый вывод

P
g
В строке 11 символов

4. Срез, который не выходит за край

Даны два слова:

long_word = "programming"
short_word = "turtle"

Для каждого слова выведи срез с 3-го по 10-й символ включительно (символы считаем с первого). Если слово короче 10 символов, срез должен просто закончиться на последнем символе. Используй для обоих слов одинаковый срез, без условий и без len().

Вопрос на подумать

Почему срез не падает с ошибкой, если его правая граница больше длины строки?

Ожидаемый вывод

ogrammin
rtle
