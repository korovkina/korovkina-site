Задачи на генераторы списков

Задачи на генераторы списков (list comprehension). Каждую задачу реши одним генератором списка — одной строкой, обычно с условием.

Полезные ссылки:

  • Генераторы списков

Напоминание:

[выражение for x in список if условие]
print([i for i in range(50) if i % 2 == 0])     — чётные числа от 0 до 48

Как решать

Код запускается прямо в браузере, вывод сразу сравнивается с ожидаемым, а решения сохраняются в этом браузере. При первом запуске загрузится Python — около 13 МБ.

1. Положительные числа

Дан список:

nums = [-3, 5, 0, 12, -7, 9, -1]

С помощью генератора создай новый список только из положительных чисел (ноль не положительный) и выведи его.

Ожидаемый вывод

[5, 12, 9]

Ctrl+Enter

2. Квадраты чётных

Дан список:

nums = list(range(1, 21))

Создай список квадратов только чётных чисел из nums и выведи его.

Ожидаемый вывод

[4, 16, 36, 64, 100, 144, 196, 256, 324, 400]

Ctrl+Enter

3. Слова без цифр

Дан список:

words = ["hi", "cat3", "dog", "7up", "apple2"]

Создай список из тех слов, в которых нет ни одной цифры, и выведи его.

Подсказка

Пригодится: str.isdigit() или str.isalpha(), any() или all()

Ожидаемый вывод

['hi', 'dog']

Ctrl+Enter

4. Без пустых строк

Дан список:

lines = ["hello", "", "world", " ", "python", ""]

Создай список только из непустых строк и выведи его. Строки, состоящие из одних пробелов, тоже считаются пустыми.

Подсказка

Пригодится: str.strip()

Ожидаемый вывод

['hello', 'world', 'python']

Ctrl+Enter

5. Делится на 3 или на 5, но не на оба

Создай список всех чисел от 1 до 100 включительно, которые делятся на 3 или на 5, но не на 3 и 5 одновременно. Выведи его.

Подсказка

Пригодится: range(), оператор %

Ожидаемый вывод

[3, 5, 6, 9, 10, 12, 18, 20, 21, 24, 25, 27, 33, 35, 36, 39, 40, 42, 48, 50, 51, 54, 55, 57, 63, 65, 66, 69, 70, 72, 78, 80, 81, 84, 85, 87, 93, 95, 96, 99, 100]

Ctrl+Enter

6. Пары из двух списков

Даны два списка одинаковой длины:

a = [1, 2, 3, 4, 5]
b = [10, 20, 30, 40, 50]

Составь пары (x, y) из элементов, стоящих на одинаковых позициях: первый элемент a с первым элементом b, второй со вторым и так далее. Оставь только те пары, где x нечётный, а y больше 20. Выведи список пар.

Подсказка

Пригодится: zip()

Ожидаемый вывод

[(3, 30), (5, 50)]

Ctrl+Enter

7. Слова длиннее среднего

Дан список:

words = ["cat", "elephant", "dog", "hippopotamus", "ant", "tiger"]

Создай список слов, длина которых строго больше средней длины слова в этом списке, и выведи его.

Подсказка

Пригодится: sum() и len(). Среднюю длину можно посчитать заранее, до генератора.

Ожидаемый вывод

['elephant', 'hippopotamus']

Ctrl+Enter

8. Только целые числа

Дан список строк:

raw = ["10", "abc", "25", "-3", "4.5", "0"]

Оставь только те строки, которые записывают целое число (в том числе отрицательное), сразу преобразуй их в int и выведи получившийся список. Остальные строки пропусти. Обойдись без try/except: всё должно уместиться в один генератор с условием.

Подсказка

Пригодится: str.isdigit() — но для "-3" он вернёт False, поэтому сначала убери минус в начале: str.lstrip("-") или срез.

Ожидаемый вывод

[10, 25, -3, 0]

Ctrl+Enter

9. Пары с чётной суммой

Дан список:

nums = [1, 2, 3, 4, 5]

Генератором с двумя циклами создай список всех пар (a, b), где a и b — элементы nums, а сумма a + b чётная. Пары упорядоченные: (1, 3) и (3, 1) — разные пары, и обе входят в ответ. Элемент может стоять в паре сам с собой, например (1, 1).

Ожидаемый вывод

[(1, 1), (1, 3), (1, 5), (2, 2), (2, 4), (3, 1), (3, 3), (3, 5), (4, 2), (4, 4), (5, 1), (5, 3), (5, 5)]

Ctrl+Enter

10. Две одинаковые буквы подряд

Дан текст:

text = "happy little bunny is hopping across a green valley"

Создай список слов, в которых хотя бы две одинаковые буквы стоят подряд, и выведи его.

Подсказка

Пригодится: str.split(), any(), range() или zip(слово, слово[1:])

Ожидаемый вывод

['happy', 'little', 'bunny', 'hopping', 'across', 'green', 'valley']

Ctrl+Enter
