Задачи на множества

Задачи на множества (set): создание, добавление и удаление элементов, пересечение, объединение и разность. Порядок элементов во множестве не определён, поэтому множества строк в ответах выводим отсортированным списком: sorted(множество).

Как решать

Код запускается прямо в браузере, вывод сразу сравнивается с ожидаемым, а решения сохраняются в этом браузере. При первом запуске загрузится Python — около 13 МБ.

1. Уникальные числа

Дан список чисел:

nums = [1, 2, 2, 3, 4, 4, 5]

Создай из него множество и выведи его. Затем выведи через пробел длину списка и длину множества.

Вопрос на подумать

Почему длина множества меньше длины списка?

Ожидаемый вывод

{1, 2, 3, 4, 5}
7 5

Ctrl+Enter

2. Уникальные символы строки

Дана строка:

s = "programming"

Создай множество уникальных символов этой строки и выведи его отсортированным списком.

Подсказка

Пригодится: set(), sorted()

Ожидаемый вывод

['a', 'g', 'i', 'm', 'n', 'o', 'p', 'r']

Ctrl+Enter

3. Добавление элемента

Дано множество:

colors = {"red", "blue", "green"}

Добавь в него цвет "yellow" и выведи множество отсортированным списком.

Подсказка

Пригодится: set.add()

Ожидаемый вывод

['blue', 'green', 'red', 'yellow']

Ctrl+Enter

4. Удаление без ошибки

Дано множество:

nums = {1, 2, 3, 4}

Удали из него число 5 так, чтобы не возникло ошибки (числа 5 в множестве нет). Тем же способом удали число 3. Выведи получившееся множество.

Подсказка

Пригодится: set.discard()

Вопрос на подумать

Что произойдёт, если удалять 5 методом remove()?

Ожидаемый вывод

{1, 2, 4}

Ctrl+Enter

5. Удаление произвольного элемента

Дано множество:

letters = {"a", "b", "c", "d"}

Удали из него один элемент с помощью pop() и сохрани удалённый элемент в переменную. Какой элемент удалится, заранее неизвестно: pop() у множества берёт произвольный элемент. Поэтому выведи каждое с новой строки:

а) True, если удалённого элемента больше нет в множестве, иначе False;

б) сколько элементов осталось в множестве.

Подсказка

Пригодится: set.pop(), оператор in, len()

Вопрос на подумать

Почему pop() у множества, в отличие от списка, не принимает индекс?

Ожидаемый вывод

True
3

Ctrl+Enter

6. Пересечение множеств

Даны два множества:

a = {1, 2, 3, 4}
b = {3, 4, 5, 6}

Найди множество элементов, которые есть в обоих множествах, и выведи его.

Подсказка

Пригодится: оператор & или set.intersection()

Ожидаемый вывод

{3, 4}

Ctrl+Enter

7. Объединение множеств

Даны два множества:

x = {"cat", "dog"}
y = {"dog", "bird"}

Создай новое множество со всеми элементами из x и y и выведи его отсортированным списком.

Подсказка

Пригодится: оператор | или set.union()

Ожидаемый вывод

['bird', 'cat', 'dog']

Ctrl+Enter

8. Объединение с обновлением

Даны два множества:

base = {1, 2, 3}
extra = {3, 4, 5}

Добавь в base все элементы из extra, изменив само множество base, а не создавая новое. Выведи base.

Подсказка

Пригодится: set.update() или оператор |=

Ожидаемый вывод

{1, 2, 3, 4, 5}

Ctrl+Enter

9. Разность множеств

Даны множества студентов, которые изучают математику и физику:

students_math = {"Anna", "Ivan", "Olga", "Lena"}
students_physics = {"Ivan", "Lena"}

Найди студентов, которые изучают математику, но не изучают физику. Выведи их отсортированным списком.

Подсказка

Пригодится: оператор - или set.difference()

Ожидаемый вывод

['Anna', 'Olga']

Ctrl+Enter

10. Быстрый поиск

Дан список слов:

words = ["apple", "banana", "cherry", "apple", "banana"]

а) Создай из него множество и выведи его отсортированным списком.

б) Проверь с помощью этого множества, есть ли в данных слово "cherry", и выведи True или False.

Подсказка

Пригодится: set(), оператор in

Вопрос на подумать

Почему проверка через множество быстрее, чем через список?

Ожидаемый вывод

['apple', 'banana', 'cherry']
True

Ctrl+Enter
