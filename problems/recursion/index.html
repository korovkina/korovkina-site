Задачи на рекурсию

Задачи на рекурсию: функция решает задачу, вызывая саму себя для задачи поменьше.

В каждой задаче уже есть заготовка функции и её вызовы. Замени pass на рекурсивное решение. Не забудь про базовый случай — момент, когда рекурсия останавливается. В задачах 1–8 циклы не используй: повторение должно получаться за счёт того, что функция вызывает саму себя. В задачах 9 и 10 цикл по элементам можно, а рекурсия нужна, чтобы спускаться во вложенные списки и папки.

Как решать

Код запускается прямо в браузере, вывод сразу сравнивается с ожидаемым, а решения сохраняются в этом браузере. При первом запуске загрузится Python — около 13 МБ.

1. Числа от 1 до n

Напиши рекурсивную функцию print_numbers(n), которая печатает числа от 1 до n, каждое на новой строке.

Подсказка

Пригодится: сначала напечатай числа до n - 1, потом само n

Ожидаемый вывод

1
2
3
4
5

4. Сумма цифр

Напиши рекурсивную функцию digit_sum(n), которая возвращает сумму цифр неотрицательного целого числа n.

Подсказка

Пригодится: n % 10 — последняя цифра, n // 10 — число без последней цифры

Ожидаемый вывод

15
7

7. Палиндром

Напиши рекурсивную функцию is_palindrome(s), которая возвращает True, если строка s — палиндром, то есть одинаково читается слева направо и справа налево, и False, если нет.

Подсказка

True
False
True

9. Числа во вложенных списках

Список может содержать числа и другие списки, а те — снова числа и списки. Напиши рекурсивную функцию count_elements(arr), которая считает все числа, в том числе внутри вложенных списков. Сами вложенные списки не считаются.

Подсказка

Пригодится: isinstance(x, list) — проверка, что x является списком

Ожидаемый вывод

6
0

10. Пути к файлам

Файловая система записана словарём: папка — это словарь, файл — ключ со значением None.

files = {
    "documents": {
        "notes.txt": None,
        "school": {
            "math.txt": None
        }
    },
    "photo.jpg": None
}

Напиши рекурсивную функцию print_paths(tree, prefix=""), которая печатает пути ко всем файлам, каждый на новой строке, в том порядке, в каком они записаны в словаре. Части пути разделяй символом /.

Подсказка

Пригодится: tree.items(), проверка value is None

Ожидаемый вывод

documents/notes.txt
documents/school/math.txt
photo.jpg

Ctrl+Enter
