Задачи на коллекции

Как решать

Код запускается прямо в браузере, вывод сразу сравнивается с ожидаемым, а решения сохраняются в этом браузере. При первом запуске загрузится Python — около 13 МБ.

1. Причесать имена

Дан список имён, записанных как попало:

names = ["  alice", "BOB ", "  charlie  "]

Одной строкой с генератором списка получи список, где у каждого имени убраны пробелы по краям и только первая буква заглавная.

Подсказка

Пригодится: str.strip(), str.capitalize()

Ожидаемый вывод

['Alice', 'Bob', 'Charlie']

sentence = "Python is a great language"

Подсказка

5. Что закончилось на складе

Дан словарь: товар → сколько штук осталось.

stock = {"apple": 5, "banana": 0, "cherry": 12, "plum": 0}

а) Генератором списка получи список товаров, которых нет в наличии.

б) Генератором словаря получи новый словарь только с товарами в наличии.

Подсказка

Ожидаемый вывод

a = [1, 2, 3, 4]
b = [3, 4, 5, 6, 1]

Склей их в один список без повторов, сохранив порядок первого появления. Подсказка: ключи словаря не повторяются и помнят порядок добавления.

Подсказка

Пригодится: dict.fromkeys(), list()

Вопрос на подумать

Почему здесь не подходит set(a + b)?

Ожидаемый вывод

15. Корзина покупок

    {"name": "eggs", "price": 120, "qty": 3},

б) Выведи заглавными буквами через запятую названия товаров, которых взяли больше одного.

Подсказка

Пригодится: sum() с генератором, str.upper(), ", ".join()
